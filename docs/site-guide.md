# 浏览本站

这是一个以研究、工程与长期写作为主的个人内容站。首页直接呈现近期内容，方便从文章开始阅读。

## 内容栏目

- **Research & Engineering**：研究、工程实践和技术笔记，支持公式、代码、图表与演示内容。
- **Essays**：阅读、生活与学习中的非技术写作。
- **Projects**：可验证的项目成果与相关资料。
- **Photos**：独立的照片栏目。
- **Archives**：按年份汇集已发布内容。

## 阅读方式

长文章提供目录、阅读进度和预计阅读时间。代码与公式可直接复制；其中的动态演示会在适合播放时启动，并尊重设备的“减少动态效果”设置。

## 搜索与显示

可使用 <kbd>Ctrl</kbd> + <kbd>K</kbd>（macOS 上为 <kbd>Cmd</kbd> + <kbd>K</kbd>）打开搜索，也可以访问搜索页面。网站提供浅色和深色显示模式，并提供中英文界面；文章标题和正文保留作者原本使用的语言。

## 订阅与链接

网站提供 RSS、站点地图和稳定的文章链接。旧文章地址会继续保留或跳转到对应的新地址，便于从搜索结果、收藏夹和外部引用继续访问。
