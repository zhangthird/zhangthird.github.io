# 设计理念

本站的设计服务于阅读和内容本身。页面保持克制，让文章、项目和照片处在视觉中心，而不是用装饰替代信息。

## 内容优先

首页让访客直接进入近期内容；主要导航只保留研究与工程、项目、随笔、照片和关于页面。归档与订阅链接放在页脚，避免把导航做得过满。

## 易读的长文

文章使用适合长时间阅读的行宽和行距。大屏幕提供目录辅助定位，窄屏则优先保证正文空间；代码和公式在不同设备上都保持可读。

## 轻量的交互

交互只用于阅读中真正有帮助的地方，例如搜索、主题切换、阅读进度和演示播放。动画保持简短，并会尊重系统的“减少动态效果”偏好。

## 可访问与响应式

键盘导航、清晰的焦点状态和语义化页面结构是基本要求。无论在桌面、平板还是手机上，页面都优先保证文字、图片、视频和操作入口能够清楚地阅读与使用。
